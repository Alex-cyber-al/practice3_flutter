# Практична робота №3. Варіант 1: Візитівка розробника

**Тема:** Розгортання робочого середовища Flutter та розробка інтерфейсу з динамічними темами

---

## 1. Опис виконаної роботи та розгортання

Під час виконання практичної роботи було налаштовано робоче середовище Flutter SDK та інтегровано його з редактором VS Code. Перевірка стану середовища за допомогою утиліти `flutter doctor` підтвердила готовність цільової веб-платформи до збірки.

Створено мобільний застосунок — електронна візитівка розробника. Інтерфейс містить аватар користувача, ім'я, посаду та контактні дані, оформлені у вигляді карток. Реалізовано функціонал динамічного перемикання світлої та темної тем через стан додатка (StatefulWidget).

---

## 2. Інструкція із запуску

Для запуску проєкту на локальній машині:

1. Склонувати репозиторій.
2. Перейти в корінь проєкту та виконати завантаження залежностей: `flutter pub get`
3. Запустити застосунок у браузері Chrome: `flutter run -d chrome`

---

## 3. Виниклі труднощі та їх розв'язання

- **Оптимізація коду віджетів:** Під час використання статичних даних лінтер `flutter analyze` видавав попередження про необхідність оптимізації коду. Проблему вирішено шляхом додавання ключового слова `const` до конструкторів віджетів картки контакту.
- **Архітектурний поділ:** Були труднощі з правильним імпортом віджета з іншого файлу. Створено окремий файл `contact_card.dart`, який успішно імпортовано в головний файл `main.dart` через відносний шлях `import 'contact_card.dart';`.
